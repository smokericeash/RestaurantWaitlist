# RestaurantWaitlist
🍽️ Restaurant Waitlist Management System
A Java-based simulation of a restaurant waitlist system built using the Queue ADT. This project explores two different seating policies and compares their performance through time-based simulation and wait-time statistics.

📌 Overview
Ever checked into a busy restaurant and been told "You're #3 on the list"? This project simulates exactly that — a digital waitlist system where customers join a queue, tables become available over time, and a host decides who gets seated next based on a configurable policy.
This was built as part of CS2400 (Data Structures) and demonstrates practical applications of the Queue ADT, algorithm design, and ADT-based system architecture.

🧠 Features

Interactive command-line interface for managing a live waitlist
Time-based simulation where the clock advances with every user input
Automatic table availability based on dining duration
Support for combining up to two tables to accommodate larger parties
Two configurable seating policies (see below)
Per-party wait time tracking with average and maximum statistics
